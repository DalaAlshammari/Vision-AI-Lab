Vision AI Lab 

An interactive computer vision application built with Python, YOLO, and Streamlit to detect objects in uploaded images.

Features

* Object detection using a pretrained YOLO model.
* Adjustable confidence threshold and visual bounding boxes.
* Detection summaries and downloadable annotated images.

Technologies

Python · YOLO · Streamlit · Pillow

Run Locally

pip install -r requirements.txt
streamlit run app.py
